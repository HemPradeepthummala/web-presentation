# Presentation-Web

The web presentation is a simple web based presentation app where the presentation is hosted on the web as html web application rather the old school method of `PPT` presentation.  
It take outs the work of the user where spending much time on the applications like `Microsoft` or `Google slides` manually drafting their presentation.  
Initially the presentation is the presentation is statically represented as the replica of a `PPT`.
then the work is deligated to the automation with some predefined templates and the type to choose.

## Plan of Action

1. Generate a static UI with basic alignment of things.
2. Add the functionality to add the content in the presentation.
3. Add the functionality to add the images in the presentation.
4. Automate the work of the user by providing some predefined templates and the type to choose.
